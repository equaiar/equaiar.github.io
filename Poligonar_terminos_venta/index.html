Términos de Venta — Poligonar

Última actualización: julio 2026

1. Información del vendedor

Equaiar (en adelante, "el vendedor"), empresa argentina dedicada al desarrollo de software. Contacto: soporte@equaiar.com.ar

2. Producto

Poligonar es una aplicación web de escritorio para visualización y mapeo de accidentes laborales sobre un mapa corporal interactivo. Se entrega como un conjunto de archivos HTML, CSS, JavaScript y datos de ejemplo listos para usar en cualquier navegador moderno, sin necesidad de servidor ni conexión a internet.

3. Precio y pago

El precio del producto se publica en el sitio web oficial. El pago se procesa a través de la pasarela de pago indicada al momento de la compra. El vendedor no almacena datos de tarjetas de crédito ni información bancaria del comprador.

4. Entrega

Una vez confirmado el pago, el comprador recibe un enlace de descarga del producto. La entrega es digital e inmediata. No hay envío físico.
